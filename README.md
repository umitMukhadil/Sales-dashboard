# Дашборд продаж

Интерактивный отчет на Streamlit: выбор периода, сравнение с прошлым периодом, разрезы по менеджерам, городам и товарам, выгрузка в CSV.

## Файлы

- `app.py` — сам дашборд
- `sales.csv` — данные (сейчас тестовые, 5 500 заказов за год)
- `generate_data.py` — генератор тестовых данных, можно удалить
- `requirements.txt` — зависимости

## Запуск на своем компьютере

```bash
pip install -r requirements.txt
streamlit run app.py
```

Откроется http://localhost:8501.

## Деплой в интернет (бесплатно, ~10 минут)

1. Создайте аккаунт на github.com, если нет.
2. Создайте новый репозиторий (например, `sales-dashboard`) и загрузите в него все файлы из этой папки — через кнопку «Add file → Upload files» прямо в браузере, без командной строки.
3. Зайдите на share.streamlit.io, войдите через GitHub.
4. Нажмите «Create app» → выберите репозиторий, ветку `main`, файл `app.py` → «Deploy».
5. Через пару минут получите ссылку вида `https://имя.streamlit.app`. Ей можно делиться, а в настройках приложения можно закрыть доступ по email.

Чтобы обновить дашборд, просто замените файл в GitHub — Streamlit подхватит изменения сам.

## Подключение своих данных

Самый простой способ: положить свой файл вместо `sales.csv` с теми же колонками:

| колонка | что это |
|---|---|
| order_id | номер заказа |
| date | дата, ГГГГ-ММ-ДД |
| manager | менеджер |
| city | город |
| product | товар |
| quantity | количество |
| unit_price | цена за единицу |
| revenue | сумма |

Если данные лежат в Google Sheets, базе или CRM, нужно заменить функцию `load_data()` в `app.py` — это задача на 10–15 строк кода, любой ИИ-агент справится по запросу «читай данные из Google Sheets по ссылке вместо sales.csv».
